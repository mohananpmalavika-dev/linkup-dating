## 4. Data Storage and Security

### 4.1 Data Storage Location

- **Primary:** Google Cloud (servers located in applicable regions)
- **Backup:** Encrypted backups
- **Duration:** Kept as long as needed for service provision

### 4.2 Data Protection Measures

We implement industry-standard security measures:
- Encryption in transit (HTTPS/SSL)
- Encryption at rest (AES-256)
- Regular security audits
- Secure password hashing (bcrypt/argon2)
- Multi-factor authentication support
- API key rotation

### 4.3 Security Limitations

While we implement strong security, no system is 100% secure. Users are responsible for:
- Strong passwords
- Protecting account access
- Not sharing personal information in messages
- Safe meeting practices

### 4.4 Data Breach Notification

If a breach occurs, we will:
- Notify affected users within 30 days
- Provide breach details and our response
- Offer security recommendations
- Comply with legal notification requirements

## 5. Your Privacy Rights

### 5.1 Access Your Data
- View your profile information within the app
- Request full data export via support

### 5.2 Correct Your Data
- Edit profile information within the app
- Update preferences and settings

### 5.3 Delete Your Data (Right to be Forgotten)

**To delete your account:**
1. Go to App Settings > Account
2. Select "Delete Account"
3. Confirm deletion
4. Account deleted immediately
5. Associated data deleted within 30 days
6. Some data retained for legal compliance (minimum period)

**Data Retained After Deletion:**
- Transaction records (accounting compliance)
- Abuse/violation reports (safety)
- Backup copies (max 90 days)
- Anonymized usage data

### 5.4 Export Your Data

Request your data in a portable format (JSON/CSV):
1. Contact: privacy@linkup-dating.com
2. Provide proof of identity
3. Receive data export within 30 days

### 5.5 Opt-Out Options

**Email Communications:**
- Unsubscribe link in every email
- Manage preferences in app settings

**Push Notifications:**
- Disable in app settings
- Disable at device OS level

**Location Tracking:**
- Disable in app settings
- Disable at device OS level
- Note: Some features require location

**Analytics:**
- Disable data collection in settings
- Use device privacy settings
